SynxPass is associated with identity, authentication, and network access in the currently known implementation. It is part of Synx Tools and is used by Morph Space.

This page documents only what the source states. It does not define a token format, signing algorithm, claims set, or key-management scheme.

<SynxPassFlow />

## What is stated

- SynxPass is a token-based system.
- The endpoint needs to refresh the token every three minutes to send data to the network.
- After registration, a user may participate in RTW and join services by getting access to ghosts.
- Morph Space uses Synx Pass for authorization.
- Access can be revoked using a token revocation endpoint.
- Session termination can be activated through Synx runtime BIOS.
- Authentication choice is architecturally optional; other token systems can be used in an RTW network.
