This section is listed in the source as a recommended RealTimeWeb.org area: specifications and version history. Written protocol text has not been supplied.

RTW is primarily a network architecture and technological framework. Compatible protocols, tools, services, and commercial products can be built on it. RTW is protocol independent: the service owner decides his own protocol in the current architectural notes.

Current known implementation facts (not a general protocol spec):

- Morph.Space and Synx tools implement MAD.
- That implementation uses TCP/IP for stateful connection and HTTPS and websocket.
- Synx BIOS currently supports XML and JSON; default is XML.
- Format can be changed at runtime by a client with domain ownership.
